# EnglishFlip 고도화 설계 계획 (수정안)

피드백을 반영하여 **단어 세트 선택**과 **Google 로그인 연동**을 제외하고, 기존 **닉네임 기반 간편 등록 체계**를 유지한 채 **안티치트(무결성 검증)**, **배경 사진 업로드 및 블러·어둡기 조절**, **상세 경기 통계·정확도 리포트**, **프로필·전적 요약 창**, **화면 집중 모드**를 통합 구현합니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> **피드백 반영 사항 (수정 완료)**
> - **제외된 항목**: 단어 세트 선택(초급·비즈니스·IT 등) 및 Google 로그인 연동은 이번 범위에서 제외합니다.
> - **유지되는 인증/랭킹 방식**: 기존과 동일하게 로그인 없이 **고유 닉네임 + 기기 식별자(`playerId`) 기반 간편 등록**으로 플레이 및 리더보드 참여가 이루어집니다.
> - **유저 프로필·전적 요약 창 조정**: Google 계정 대신 **등록된 닉네임과 `playerId` 기준**으로 누적 전적(경기 수, 승률, 최고 기록, 평균 정확도, 최고 CPM) 및 최근 경기 이력을 보여줍니다.

> [!NOTE]
> **구현 시 적용할 기본 정책**
> 1. **안티치트 및 비정상 기록 차단**: 붙여넣기·드래그 입력 차단, 비신뢰(`isTrusted === false`) 입력 이벤트 및 비정상적 매크로 입력 리듬 탐지 시 해당 경기의 리더보드·전적 반영만 제외하며, 정상 플레이어는 어떤 제약도 느끼지 않도록 설계합니다.
> 2. **전적 데이터 저장 범위**: 이메일·계정 정보 등 개인정보(PII)를 수집하지 않고, 익명 `playerId` 기준의 비식별 경기 통계(점수, 승패, CPM, 정확도, 랭크)만 저장합니다.

## 1. Overview & Core Concept

- **무엇을 구현하는가**: 기존 영어 단어(60타일) 1분 대결 구조를 그대로 유지하면서, ① **안티치트 입력 무결성 검증**, ② **배경 사진 업로드 + 블러·어둡기 실시간 조절**, ③ **경기 종료 후 상세 정확도·페이스 리포트**, ④ **닉네임 기반 프로필 및 최근 전적 요약 창**, ⑤ **타이핑 중 주변 UI 자동 숨김(화면 집중 모드)** 을 추가합니다.
- **대상 사용자 및 맥락**: 기존 EnglishFlip 플레이어가 공정한 리더보드 환경에서 집중력 있게 타수를 측정하고, 자신의 오타 패턴과 성장 추이를 직관적으로 확인하며 화면을 취향대로 꾸밀 수 있도록 합니다.
- **핵심 가치**:
  - 기존 단어 풀과 간편한 닉네임 접속 흐름을 깨지 않으면서도,
  - 매크로·복사 붙여넣기 치팅을 걸러내 랭킹 신뢰도를 높이고,
  - 시각적 몰입감(커스텀 배경 + 집중 모드)과 데이터 피드백(정확도 리포트 + 전적 창)을 제공합니다.

## 2. User Experience & Visual Design

### 핵심 사용자 흐름 (User Flows)

1. **기존 진입 및 간편 닉네임 흐름 유지**:
   - 최초 방문 시 기존처럼 고유 닉네임을 설정하고 곧바로 시작 화면에서 AI 속도(200 / 400 / 600 / 800타)를 선택해 플레이합니다.
2. **배경 사진 업로드 & 블러·어둡기 조절 (디자인 설정)**:
   - 디자인 설정에 **배경 사진** 섹션을 추가해 로컬 이미지 파일(JPG/PNG/WebP)을 업로드할 수 있습니다.
   - 업로드 즉시 미리보기가 반영되며, **블러(0~24px)** 와 **어둡기(0~85%)** 슬라이더로 텍스트·타일 가독성을 세밀하게 맞출 수 있고 `배경 삭제` 버튼으로 언제든 기본 테마 배경으로 돌아갑니다.
3. **화면 집중 모드 (게임플레이 설정)**:
   - `화면 집중 모드` 토글을 켜면 카운트다운 종료 후 타이핑을 시작하는 순간 상단 헤더 버튼, 하단 푸터, 보조 안내 문구가 부드럽게 사라져 보드와 입력창만 남습니다.
   - 마우스를 움직이거나 `Esc` 키를 누르거나 경기가 종료되면 숨겨졌던 UI가 즉시 자연스럽게 복원됩니다.
4. **안티치트 검증 (플레이 중 & 종료 시)**:
   - 입력창에 대한 붙여넣기(`Ctrl+V` / 우클릭 붙여넣기)와 텍스트 드래그는 즉시 차단됩니다.
   - 내부적으로는 실제 키 입력 신뢰도(`isTrusted`), 키 입력 간격(Inter-Key Interval) 분산, 실제 경기 경과 시간(≥ 59초)을 측정합니다. 매크로·스크립트 변조 등 비정상 입력이 감지되면 결과 화면에 안내 문구를 표시하고 해당 판은 리더보드와 전적 기록에 반영하지 않습니다.
5. **상세 경기 통계 & 정확도 리포트 (결과 화면)**:
   - 경기 종료 후 결과 모달에 승패·점수·랭크와 함께 **유효 타수(CPM)**, **원시 타수(Raw CPM)**, **정확도(%)**, **단어당 평균 소요 시간(초)** 4개 핵심 지표를 표시합니다.
   - **10초 구간별 타수 추이(0~60초 6구간 막대 차트)** 와 **오타 또는 입력 지연이 가장 컸던 단어 Top 4**를 함께 제공합니다.
6. **프로필 및 전적 요약 창 (상단 헤더 아이콘)**:
   - 상단 헤더(리더보드 버튼 옆)에 **프로필 아이콘 버튼**을 배치해 클릭 시 현재 닉네임, 최고 랭크, 누적 경기 수, 승률(%), 평균 정확도(%), 최고 CPM, 최근 경기 목록을 한눈에 볼 수 있는 모달을 엽니다. (닉네임 변경 바로가기 포함)

### 시각적 정체성 및 레이아웃 원칙

- **무테두리 명도 계층 일관성**: 모든 신규 UI(프로필 모달, 확장 결과 리포트, 배경 사진 설정 카드)는 기존과 동일하게 `1px` 테두리를 사용하지 않고 `surfaceElevated` → `surface` → `bg` 배경색 대비와 `tabular-nums` 고정폭 숫자로 정렬합니다.
- **배경 가독성 스크림**: 업로드된 배경 이미지가 밝거나 복잡해도 전경 타일·글꼴 명도 대비가 유지되도록 GPU 가속 블러 레이어(`scale(1.06)`로 가장자리 흐림 여백 제거) 위에 사용자 조절 어둡기 오버레이(`rgba(0,0,0, dim)`)를 적용합니다.
- **제로 필(Zero-Pill) 규율**: 통계 항목과 오타 단어 목록은 캡슐 배지 대신 깔끔한 배경 톤 셀과 `·` 구분 기호로 정돈합니다.

## 3. Key Product Decisions & Trade-Offs

- **결정 1: 비로그인 구조에 최적화된 클라이언트 안티치트 + Firestore 규칙 강화**
  - *선택한 방식*: ① `onPaste` / `onDrop` 차단 및 `event.isTrusted` 검증, ② 키 입력 간격(IKI) 분산·물리적 불가능 연타(10ms 미만 연속 입력 및 키다운 없는 다중 문자 삽입) 탐지, ③ 경기 경과 시간(≥ 59초) 검증, ④ Firestore 보안 규칙에서 현실적인 `bestFlips` 상한(예: `<= 320`), `bestCpm` / `bestAccuracy` 범위 제한, 단조 증가 규칙을 강제합니다.
  - *이유*: 별도 로그인이나 커스텀 서버 없이도 일반적인 복사 붙여넣기, 브라우저 콘솔 스크립트 매크로, 단순 값 변조를 효과적으로 걸러낼 수 있습니다.
  - *트레이드오프*: 향후 Google 로그인 등 서버 인증을 도입하면 계정 단위 차단이나 서버 사이드 검증으로 한 단계 더 강화할 수 있는 여지를 남긴 채, 현재 구조에서 가장 실용적인 방어선을 구축합니다.

- **결정 2: 배경 이미지 브라우저 IndexedDB 저장 + Canvas 자동 압축**
  - *선택한 방식*: 사용자가 업로드한 이미지를 브라우저 `<canvas>`에서 최대 너비 1920px 이하 WebP/JPEG로 압축해 **IndexedDB**에 저장하고, 블러(`0~24px`) 및 어둡기(`0~85%`) 수치만 설정 JSON에 보관합니다.
  - *이유*: `localStorage` 5MB 용량 초과 오류나 Firestore 1MB 문서 제한 걱정 없이 고해상도 사진도 빠르고 안전하게 저장·복원할 수 있습니다.

- **결정 3: 프로필·전적 데이터의 로컬 + 클라우드 병행 구조**
  - *선택한 방식*: 상세 최근 경기 목록(최대 20경기)과 누적 통계 요약은 브라우저 로컬 저장소 및 `playerId` 기반 Firestore 프로필 문서에 함께 관리합니다.
  - *이유*: 로그인 없이도 기기 내 즉시 조회가 가능하며, 네트워크 지연 시에도 전적 화면이 빈 상태 없이 빠르게 열립니다.

### 데이터 모델 및 상태 전략

1. **안티치트 및 경기 텔레메트리 (클라이언트 메모리)**
   - 매 입력마다 `rawKeystrokes`, `mistakeKeystrokes`, `wordStartAt`, `interKeyIntervals[]`, `bucketCorrectChars[6]`(10초 단위 6구간), `wordStatsMap`을 기록합니다.
   - 비정상 판정(`cheatDetected: boolean`, `cheatReason?: string`):
     - `isTrusted === false` 이벤트 발생 시 즉시 플래그.
     - 키다운 이벤트 없이 입력 길이가 한 번에 2글자 이상 증가하거나, 연속된 키 간격 표준편차가 극단적으로 낮으면서 평균 < 15ms인 기계적 패턴 탐지 시 플래그.
     - 종료 시 실제 경과 시간 < 59초 또는 현실적 상한 초과 시 랭킹 반영 차단.

2. **유저 프로필 및 전적 요약 (로컬 캐시 + Firestore `playerId` 문서)**
   - 기존 `/leaderboard/{playerId}` 및 `/nicknames/{nicknameKey}` 구조는 유지하되, 검증된 요약 필드(`bestCpm`, `bestAccuracy`)와 선택적 전적 목록(`/playerProfiles/{playerId}/matches/{matchId}`)을 연계할 수 있도록 스키마와 `firestore.rules`를 동기화합니다.
   - `ProfileModal`에서는 `totalGames`, `wins`, `winRate`, `bestFlips`, `bestRank`, `bestCpm`, `avgAccuracy`, `recentMatches[]`를 표시합니다.

3. **커스텀 배경 이미지 상태 (IndexedDB + GameSettings)**
   - IndexedDB에 압축된 Blob을 저장하고 앱 마운트 시 Object URL로 로드합니다(교체/삭제/언마운트 시 `URL.revokeObjectURL`로 메모리 정리).
   - `GameSettings`에 `hasCustomBackground`, `backgroundBlur`(기본 `6`), `backgroundDim`(기본 `45`), `focusMode`(기본 `false`)를 추가해 `localStorage`에 유지합니다.

### 인터랙션 및 상태 전이 매핑

- **배경 사진 업로드**: 파일 선택 → MIME 및 크기 검증 → `<canvas>` 리사이징 → IndexedDB 저장 → 즉시 배경 레이어 반영 → 블러/어둡기 슬라이더 드래그 시 실시간 스타일 갱신.
- **화면 집중 모드**: `settings.focusMode === true` && `status === 'PLAYING'` && 첫 타이핑 입력 발생 → `isFocusDimmed = true` (상하단 UI `opacity-0 pointer-events-none`) → `mousemove` / `keydown(Escape)` / `status !== 'PLAYING'` 시 `isFocusDimmed = false`.
- **경기 종료 리포트**: `finishGame()` 실행 시 60초 텔레메트리를 집계해 `MatchReport` 생성 → `cheatDetected`가 `false`일 때만 `bestFlips` 갱신, 리더보드 동기화, 전적 목록 추가 → `ResultModal`에 점수·랭크·정확도·10초 구간 차트·오타 단어 리포트 렌더링.
